#### 服務提供者基本與任職資訊-Questionnaire TWSS Base

本 Profile 用於定義服務提供者是否為親屬保母與健康檢查日期的表單。表單的 `subjectType` 為 PractitionerRole，回覆資料應使用「服務提供者任職表單回覆-QuestionnaireResponse TWSS Base」。

實作者可能可以（MAY）支援 FHIR R4 Questionnaire 所定義之查詢參數；更多內容請參考 [FHIR R4 Questionnaire 查詢參數](https://hl7.org/fhir/R4/questionnaire.html#search)。
